## 2. 何のアプリか

Slack・X・Instagram・Threads・LINE公式・note・議員の告知・チラシ画像などの告知を、LINE オープンチャットにそのまま貼れる文章に整える PWA です。

- **① トーク本体**: AI の提案（タイトル・箇条書きの概略・日時など）から組み立てる。画面で手直しできる。
- **② スレッド**: 前置き＋**原文そのまま**（AI を通さない）。長文は分割する。
- **③ 記録**: Google スプレッドシートに保存し、一覧から探せる。

記録の一覧ページ（`archive.html`）と、公開用スプレッドシート（「記録一覧」タブ）にも自動で反映されます。

## 5. 決まっている仕様と、その理由（蒸し返さない）

- **曜日は LLM に任せない**（コードで計算）。「本日」「明日」はコピーした時点で付ける。
- **スレッドの原文は一字も変えない**。例外は、利用者がボタンを押したときだけ（要約・絵文字の名前の除去）。分割しても、つなぐと原文に戻る。
- 日付が未確定（「または」「未定」など）なら、日時を空にして警告する。AI の `dateUncertain` と、原文からの機械的な検出の両方で判定する。
- 参加 URL・申込 URL は、**原文に実際にある URL だけ**を残す（`findUrlInText_`）。`https://` なしの書き方（`meet.google.com/…`）も拾い、`https://` を補う。
- URL は外部の短縮サービスを使わない。追跡用のパラメーターを取り除くだけ（`cleanUrl_`）。
- トーク本体の書式: タイトルを【】で囲む、概略は体言止めの箇条書き、スケジュールは「いつ・どこで」、場所は「対面（高崎）＆オンライン」の形、最後に「詳細はスレッドにて ➡️」。スレッドを使わないときは「全文はこちら ⬇️」と URL。
- スレッドの前置きは、**全文（初期値）／抜粋の選択で書き分ける**。発信者の有無では切り替えない（名前があれば「発信者は○○です。」を足すだけ）。「（全文）」とは書かない。抜粋を選んでも、アプリは文を削らない。
- 絵文字の名前（`:○○:`）の除去: ボタンを押したときだけ。行の最後で消したら、句読点・閉じかっこがなければ「。」を付ける。時刻（`21:20`）・URL・ふつうのコロンは消さない。末尾の「（編集済み）」も消す。
- 種別（お知らせ／スケジュールなど、トークの形を決める）とカテゴリ（記録の分類）は別物のまま残す（利用者が判断済み）。
- 種別は、組み込みの3つ（`Config.gs` の `kinds`。消せない）に加え、設定画面から追加・削除できる（名前・説明・「日時あり」の選択。最大20個）。「日時あり」（`schedule`）の種別は、トークに日時・場所の行を出す。`schedule` キーの種別は、設定に印が届かなくても日時を出す（`Config.gs` が古いままでも壊れないため）。追加した種別を消すと、その種別の保存済みの記録は、開くと種別が未選択になる。
- タグ検索は、複数のタグを選んだとき、初期値は OR（どれか1つでも持つ）で、「すべて持つ」（AND）に切り替えられる（`tagMode`）。
- **参加 URL（オンライン会議・配信の URL）はトークに出さない**（利用者の希望）。欄・記録・公開一覧のリンク・スレッドの原文には残す。申込 URL は出す。
- 概略（記録の `summary`）には、「詳細はスレッドにて ➡️」「全文はこちら ⬇️」を入れない。AI の結果と保存前に取り除く（`stripThreadGuide_`）。この結びはトーク本体にだけ付く。
- 画面・文書での呼び名は「記録の一覧」（旧「公開の一覧（ページ）」）に統一。「公開用スプレッドシート」の呼び名は変えない。記録の一覧に出すトーク本文からは「詳細はスレッドにて ➡️」だけを取り除く（`toPublicItem_`。「全文はこちら ⬇️」と URL・原文は残す）。
- 表示名は「発信者／出演者」（入力アプリ・記録の一覧ページ・公開用シート）。**保存先シートの見出しは「発信者」のまま**（列を見出しの名前で探すので、変えると既存のシートを読めなくなる）。スケジュール型の「出演者」（トークの 🎤 の行）は別の欄。
- 公開用シートの並びは、カテゴリを先頭側に、種別を末尾に置く（カテゴリと取り違えられないため）。種別の列は、まだ非表示にしていない。後日非表示にするか、このまま表示するかは未定（利用者が決める）。列は `Config.gs` の `publicSheet.columns` で変えられる。非表示は列の位置に付くので、並びを変えたら非表示を確かめ直す。
- シートの列は見出しの名前で探す（列の並びに頼らない）。発信者は「種別」と「ソース」の間。旧「メモ」列は「コメント」として読む。
- 公開用スプレッドシートには、ID とコメント以外を載せる。トーク本文の列は載せない。タイトルは元の投稿へのリンク。
- Gemini が 500/503/504 なら、3秒待って1回だけやり直す。429 はやり直さない。どちらも日本語のエラーにする。
- 費用は無料枠・少額が前提。AI の使用量は「利用量」シートに記録し、設定画面で今月の概算（円）を表示する。
