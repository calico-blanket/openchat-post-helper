本文へ移動

オープンチャット投稿ヘルパー

  • アプリに戻る

使い方

告知や記事を、LINE オープンチャットに貼りやすい文章に整えるアプリです。トーク本体（①）とスレッド（②）に貼る文を作り、記録（③）として保存します。

はじめに（最初の1回だけ）

  1. 招待した人から届いた招待リンクを開きます（スマホは Chrome、PC は Chrome か Edge がおすすめです）。
  2. 「名前を登録して始める」が出たら、あなたの名前を入れて「登録する」を押します。入力の画面になれば準備はできています。名前は30文字までで、ほかの人と同じ名前は使えません（記録の「保存した人」として使われます）。
  3. アプリとしてスマホや PC にインストールしておくと、次から開きやすくなります。
    • スマホ（Android）: Chrome のメニュー（右上の︙）から「ホーム画面に追加」または「アプリをインストール」を選びます。スマホの「共有」から使うには、この手順が必要です。
    • スマホ（iPhone）: Safari で開き、画面下の共有ボタン（□から↑が出ているマーク）を押して「ホーム画面に追加」を選びます。iPhone は、ほかのアプリの「共有」からは使えないため、ホーム画面のアイコンから開いて使います。
    • PC: アドレス欄の右にあるインストールのアイコンを押します。ブックマークに登録して使うこともできます。Edge なら、3点リーダー（…）から「その他のツール」＞「タスクバーにピン留めする」がおすすめです。

招待リンクは、あなた1人用です（ほかの人には渡さないでください）。発行から7日以内に開いてください。あなたの端末2台まで使えます。スマホと PC の両方で使いたいときは、同じリンクを2台目でも開き、1台目と同じ名前を入れて「登録する」を押してください（同じ人として使えるので、自分が保存した記録をどちらからも直せます）。3台目以降は、招待した人に新しいリンクを作ってもらってください。

投稿文を作る

スマホと PC で、始め方が違います。

ご注意: Slack の投稿は、URL を入れても本文が取れません。本文をコピーして「本文」の欄に貼ってください（詳しくは下の「スマホ・PC 共通の注意」）。

スマホ（Android）の場合: 「共有」から始める

  1. X・Instagram・Threads・YouTube・note などのアプリやブラウザで、転載したい投稿を開き、「共有」を押します。
  2. 共有先の一覧から「投稿ヘルパー」を選びます（出てこないときは、「はじめに」のアプリとして入れる手順をしてください）。
  3. アプリが開き、URL が入って、「文章を整える」が自動で始まります。ボタンを押す必要はありません。少し待つと、結果の画面になります。

iPhone は「共有」から開けないため、次の PC と同じ手順（URL を貼って「文章を整える」を押す）になります。

PC の場合（スマホで共有を使わない場合も同じ）: URL や本文を貼り付けて、ボタンを押す

  1. 転載したい投稿の URL をコピーします。
  2. アプリの「新規」の画面で、「元の投稿・記事の URL」に貼り付けます。
  3. 「文章を整える」を自分で押します（PC では自動では始まりません）。少し待つと、結果の画面になります。

スマホ・PC 共通の注意

  • Slack の本文を「本文」の欄に貼り付けて「文章を整える」を押すと、その本文から文章が作られます（スマホで共有したときも、本文を貼り直してから押します）。
  • スマホで、Slack の文を「共有」すると、長い URL は「drive.google.com/…」のように、アプリ上でも省略されたままです。PC でのアプリ利用をおすすめします。（PC 版の Slack では URL は省略されません。）
  • スマホでアプリを使い、省略された URL をスレッドに貼り付けた場合は、正しい URL を入力しなおす必要があります。
  • メールやチャットなど URL が無い文章は、「本文」の欄に貼って「文章を整える」を押すと使えます。
  • チラシの画像は、「画像を選ぶ」で選んでから「文章を整える」を押すと、画像の文字から文章が作られます。選べる画像は、JPEG（.jpg / .jpeg）・PNG（.png）・WebP（.webp）です。
  • 「AI を使わずに手で作る」を押すと、AI を使わず、自分で書く画面になります。
  • 貼り付けた本文は、スレッド用の文章としてそのまま転記できるようになっています。
  • 「文章を整える」は、30秒以上かかることがあります。ボタンが「整えています…」になっているあいだは、画面を閉じずにお待ちください（押し直さなくて大丈夫です）。

結果の画面をコピーして貼る

画面の上から、①→②→③の順に進めます。

黄色の「確認してください」が出たら、①の前に読んでください（日付があいまい、URL を外した、など）。

① トークに貼る

「トーク本体をコピー」を押すと、トーク用の文がコピーされます。オープンチャットのトークに貼ります。コピーする前に、文を確かめてください（そのまま直せます）。

  • 「本日」「明日」は、コピーした時点の日付で付きます。前の日に作った文でも、コピーし直せば正しくなります。
  • 開催日時は、必ず原文と見比べてください（③の「開催日時など」で直せます。曜日は日付から自動で付きます）。

② スレッドに貼る

「1通目をコピー」「2通目をコピー」…を順に押すと、1通ずつコピーされます。①で貼った投稿のスレッドに、1通ずつ貼ります。

  • 「スレッドにも投稿する」を外すと、スレッドを使わない形になります。トーク本体の最後に「全文はこちら ⬇️」と URL が付きます。
  • 長い原文は、「長いときは要約する」で「半分程度」か「3行程度」を選んで「要約する」を押すと、AI が要点を拾って短くします（前置きが「…の要約です。」に変わります。「原文に戻す」で戻せます）。

③ 記録する

タイトル・種別・カテゴリなどを確かめて「保存する」を押すと、記録として保存され、あとで一覧から探せるようになります。コピーだけで終わらせるときは、保存しなくても使えます。

③の項目を直すと、①の文も自動で作り直されます（①を手で直したあとは、自動では変わりません。「③の項目から作り直す」で作り直せます）。

「同じ URL の投稿がすでに保存されています」と出たときは、前に保存した記録があります。同じ内容なら、一覧から開いてコピーするほうが早いです。そのまま「保存する」を押すと「それでも保存しますか？」と確認が出ます。

記録欄の項目の意味と直し方

AI が入れた値は、保存する前に必ず見直してください。直すところは、画面の項目をそのまま書き換えます。

発信者／出演者
元の投稿をした人・団体の名前です。トークの出典行とスレッドの前置きに入ります（空なら名前なしの文になります）。下の候補ボタンを押すか、自由に書けます。候補の追加は、招待した人に頼んでください。
タイトル（必須）
トークでは【】で囲まれます。自分で【】を付ける必要はありません。
概略
箇条書きの要点です。トークに入ります。「詳細はスレッドにて」のような結びは、自動で付くので書かなくて大丈夫です。
種別（必須）
トークの形が決まります。「スケジュール」は日時が決まっているイベントなどで、トークに日時・場所・出演者などの行が入ります。「記事」「議員活動」は、日時の行が出ません。日時のある告知なのに「記事」になっていたら、「スケジュール」に直してください。
入力元・元の URL
どこから転載したかです。URL は追跡用の部分を取り除いた形に整えてあります。
発信日
元の投稿が出た日です。X・Instagram・Threads・Slack は URL から、YouTube は自動で入ることがあります。note・チラシ・LINE などは入らないので、分かるときだけ入れてください。空のままでも保存できます。
開催日時など（スケジュールのとき。必ず原文と見比べる）
  • 開催日・開始時刻・終了時刻: 曜日は日付から自動で付きます（AI には任せていません）。原文の日時が決まっていない（「または」「未定」など）ときは、日時が空になり、黄色の「確認してください」が出ます。
  • 場所: 「対面＆オンライン」「オンライン」「渋谷」のように短く書きます。テレビ番組への出演は「テレビ」になります。
  • 配信・会議の URL: 記録には残りますが、トーク本体には出ません（オープンチャットで関係のない人が入ってこないように）。
  • 出演者: トークに「🎤 出演: …」の行が入ります。
  • 申込締切・申込 URL: 締切はトークに「⏰ 申込締切: …」の行が入ります。申込 URL を入れると、トークに「📝 要申し込み」の行が入り、その次の行に URL が入ります。URL を出したくないときは、①のトーク本体でURL の行だけ消すと、「📝 要申し込み」だけが残ります。
カテゴリ（必須）・タグ
記録の分類です。一覧の絞り込みに使います。選ぶだけで、新しいカテゴリ・タグの追加は、招待した人に頼んでください。

文を手で直す

  • ①トーク本体は、そのまま書き換えられます。削る・書き足すのは自由です。
  • ②スレッドは、「スレッドの内容を直す」を開くと、前置き・原文・コメント（スレッドの最後に添える一言）を直せます。原文は AI を通さず、貼った文のまま使われます。不要な行は、ここの原文から消せます。長いスレッドは、LINE の文字数に合わせて自動で分けて表示されます（つなぐと原文に戻ります）。
  • Slack からコピーした文に、絵文字の名前（:sparkles: など）が文字のまま残っているときは、「絵文字の名前を取り除く」ボタンが出ます。押すと、名前と末尾の「（編集済み）」を取り除きます。「取り除く前に戻す」で戻せます。
  • 文を直したら、コピーのボタンを押し直してください。押す前にコピーした文は、直す前のままです。

一覧・検索

  • 上の「一覧・検索」を押し、キーワードやカテゴリ・タグで「検索」します。
  • 「開く」で、保存した文をもう一度コピーできます。開くと、③の項目の画面になります。
  • 「記録の一覧ページ」（設定の画面から開けます）は、合言葉なしで誰でも読める、記録の一覧です。オープンチャットには、このページの URL を貼ります。
  • 自分が保存した記録は、開いて直して「更新する」、または「削除」できます。
  • ほかの人が保存した記録は、開いてコピーすることだけができます（直したいときは、保存した人か、招待した人に頼んでください）。

設定の画面

上の「設定」を押すと開きます。入力する人に出るのは、次の4つです。

  • 接続: 「（あなたの名前）さんとして、招待リンクで接続しています」と出ます。合言葉は端末の中に保存されていて、画面には出ません。別の人に端末を譲るときや、使わなくなったときだけ、「接続を解除する」を押します（保存した記録は消えません）。
  • 記録の一覧ページ: 誰でも読める記録の一覧を、新しいタブで開きます。読むだけで、直したり消したりはできません（直すときは、アプリの「一覧・検索」で記録を開きます）。
  • 公開用スプレッドシート: 保存した記録の表を、新しいタブで開きます（くわしくは下の「公開用スプレッドシートについて」）。
  • 所要時間の記録: 「文章を整える」にかかった時間の記録です（この端末の中だけ）。「記録を消す」で消せます。

公開用スプレッドシートについて

記録を保存・更新・削除すると、記録の一覧の表（Google スプレッドシートの「公開用シート」）も自動で書き換わります。トーク本文を含め、保存した内容がほぼそのまま並ぶので、一覧でさっと見たいときに使えます。

  • 表は見るだけです。表で直しても記録は変わらず、次に誰かが保存・更新・削除したときに、元の内容に書き直されます。
  • 設定の画面の「公開用スプレッドシート」の「公開用スプレッドシートを開く」から、いつでも開けます（記録の一覧ページの「スプレッドシートで表として見る」からも開けます）。
  • 表に反映されていないときは、招待した人に伝えてください（管理者が「公開用シートを作り直す」で直せます）。

カテゴリ・タグ・種別・発信者の候補の追加や削除、招待の発行、AI の使用量は、招待した人（管理者）だけの設定です。追加してほしいものがあれば、招待した人に頼んでください。

困ったとき

「この招待リンクは使えません」と出た
そのリンクは、使用済み・期限切れ（7日）・取り消し済みのどれかです。招待した人に、新しい招待リンクを作ってもらってください。
端末を替えた・ブラウザのデータを消した・シークレットウィンドウを閉じたら、使えなくなった
登録の情報はその端末の中にだけあるため、消えると使えなくなります。招待した人に新しい招待リンクを作ってもらい、登録し直してください（前と同じ名前を使うときは、招待した人に前の名前を消してもらいます）。
「この合言葉は、いまは使えません」と出た
招待した人が、あなたの利用を止めています。招待した人に連絡してください。
スマホの「共有」に「投稿ヘルパー」が出てこない
アプリとして入れていない可能性があります。「はじめに」の、アプリとして入れる手順（「ホーム画面に追加」）をしてください。それでも出ないときは、PC と同じ手順（URL を貼って「文章を整える」を押す）で使えます。
本文が取れない・内容がおかしい
サイトによっては本文が取れません。本文をコピーして「本文」の欄に貼ってから、もう一度「文章を整える」を押してください。
「文章を整える」が終わらない・エラーになった
30秒以上かかることがあります。1分以上たっても終わらない、またはエラーが出たときは、少し待ってからもう一度「文章を整える」を押してください（AI が混み合っていると、断られることがあります）。それでもだめなときは、招待した人に、エラーの文を伝えてください。
日時や場所が空になった・違っている
原文に日時がはっきり書かれていない、または複数の候補があると、空になります。③の「開催日時など」に、原文を見ながら入れてください。
自分で保存した記録なのに、直せない・削除できない
端末を替えて登録し直したときは、前の名前の記録を、新しい名前では直せません（別の人として扱われるため）。招待した人に頼んでください。
別の人に端末を譲る・もう使わない
「設定」の「接続を解除する」を押してください。保存した記録は消えません。
